# 🐱 Cat Mario: Bouncing Ball Edition

這是一個基於 HTML5 Canvas 和原生 JavaScript 開發的 2D 橫向捲軸平台跳躍遊戲。
遊戲特色是一隻可愛的橘色貓咪球，擁有 Q 彈的物理效果與流暢的動作動畫。玩家需要躲避敵人、收集金幣、跨越障礙，並在最後關卡挑戰大魔王。

## ✨ 特色 (Features)

* **無外部素材依賴 (No External Assets)**：所有的圖形（貓咪、敵人、背景、UI、金幣）皆使用 JavaScript Canvas API 即時幾何繪製，單一 HTML 檔案即可運作。
* **幾何像素風格 (Geometric Pixel Art)**：結合了像素風格的背景（無縫地面、像素太陽）與高解析度的幾何角色設計。
* **物理動畫系統**：
    * **Squash & Stretch**：角色跳躍與落地時有生動的擠壓與拉伸變形效果。
    * **滾動動畫**：雙重跳躍與移動時，角色會根據速度進行自然的滾動運算。
* **動態關卡生成**：
    * 無縫連接的地面渲染技術（消除接縫黑線）。
    * 隨機生成的平台、坑洞、敵人與金幣配置。
* **完整遊戲循環**：包含「遊戲教學 (How to Play)」、「遊玩」、「BOSS 戰」、「勝利/失敗」畫面。

## 🎮 如何遊玩 (How to Play)

遊戲開始前會有教學畫面，按下 **Enter** 鍵進入關卡。

### 操作方式 (Controls)

| 動作 | 按鍵 |
| :--- | :--- |
| **移動 (Move)** | 方向鍵 `←` `→` |
| **跳躍 (Jump)** | `空白鍵 (Space)` |
| **雙重跳躍 (Double Jump)** | 在空中再次按下跳躍鍵 (會觸發翻滾動作) |
| **開始遊戲 (Start)** | 在標題畫面按下 `Enter` |

### 遊戲目標 (Objective)

1.  **存活**：避開**深灰色貓咪球 (敵人)** 和隨機生成的**地洞**。
2.  **戰鬥**：從上方**踩踏**敵人的任何部位（判定寬鬆）可以消滅牠們並獲得分數。
3.  **收集**：收集散落在地上與空中的 **金幣** (+100分)。
4.  **過關**：抵達終點的 **門** 即可進入下一關。
5.  **BOSS 戰**：在 **Level 6** 擊敗巨大的 **惡魔貓 BOSS**！(BOSS 會在地上滾動攻擊)

## 🚀 安裝與執行 (Installation)

本專案不需要任何伺服器或依賴庫。

1.  下載本專案的 `index.html` 檔案。
2.  直接使用瀏覽器（Chrome, Firefox, Edge 等）開啟該檔案。
3.  開始遊戲！

## 🛠️ 技術細節 (Technical Details)

* **渲染引擎**：HTML5 Canvas 2D Context。
* **遊戲迴圈**：使用 `requestAnimationFrame` 實現 60FPS 流暢畫面。
* **繪圖技術**：
    * 使用 `ctx.arc`, `ctx.ellipse` 繪製幾何貓咪。
    * 使用 `ctx.transform` 進行矩陣變換以實現旋轉與彈性變形。
    * 程式化生成像素雜點與背景漸層。
* **碰撞檢測**：
    * **AABB (Axis-Aligned Bounding Box)**：用於矩形平台與地面檢測。
    * **圓形碰撞 (Circle Collision)**：用於貓咪球與敵人/金幣/BOSS 之間的互動。
* **狀態機**：管理 `HOW_TO_PLAY`, `START`, `PLAYING`, `GAME_OVER`, `WIN` 等遊戲狀態。
